Amazônia Molecular — aplicação web interativa

O Amazônia Molecular é um projeto que reúne informações sobre plantas medicinais e compostos químicos associados a essas espécies, permitindo explorar representações tridimensionais de estruturas moleculares.

A proposta é aproximar os conhecimentos sobre a biodiversidade amazônica dos conteúdos científicos, utilizando a tecnologia como ferramenta de pesquisa, aprendizagem e visualização.

01

Objetivo do projeto

Organizar informações sobre plantas medicinais e possibilitar a exploração visual de compostos químicos relacionados a elas, tornando o estudo das moléculas mais interativo e acessível.

02

Biologia

Contribui para a compreensão das espécies vegetais, suas características e sua relação com a biodiversidade amazônica, considerando também os conhecimentos tradicionais sobre plantas.

03

Química

Permite explorar informações sobre compostos químicos, fórmulas moleculares e representações tridimensionais, aproximando conceitos químicos de recursos visuais.

04

Informática

Utiliza tecnologias de desenvolvimento web para organizar os dados, realizar buscas, apresentar informações e possibilitar a visualização interativa das estruturas moleculares.

Tecnologias utilizadas

O desenvolvimento integra diferentes ferramentas para construir a interface, organizar as informações e apresentar as estruturas moleculares em três dimensões.

HTML5 CSS3 JavaScript 3Dmol.js PubChem

HTML, CSS e JavaScript são utilizados no desenvolvimento da aplicação. A biblioteca 3Dmol.js permite visualizar estruturas moleculares em 3D, enquanto o PubChem fornece dados químicos e estruturas de compostos identificados por seus CIDs.

Possibilidades futuras

O projeto poderá receber novas funcionalidades para ampliar suas possibilidades de pesquisa e aprendizagem.

Banco de dados SQL

Estruturar e armazenar informações sobre plantas, compostos químicos e suas relações.

Estruturas moleculares em 2D

Implementar a possibilidade de exportar ou baixar representações bidimensionais das moléculas.

Modelos moleculares em 3D

Explorar a criação de modelos físicos por impressão 3D, mediante a conversão das estruturas para formatos adequados à modelagem e à fabricação.

As funcionalidades acima representam possibilidades futuras, não recursos já implementados.
